Capture measures image reads. Delivered and decoded FPS use Xpra frame boundaries; partial updates are counted separately. These are not the game's FPS. A static screen can produce few updates.

CPU: 100% = one core. Data/hour projects the current image payload rate and excludes audio, protocol and TLS overhead. Bandwidth is an adaptive encoding budget, not a strict network traffic shaper. RSS sums can count shared pages repeatedly; PSS apportions them. Container memory also includes page cache and kernel usage. Game metrics include Wine processes adopted by the container init.
